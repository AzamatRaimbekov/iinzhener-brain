## Тяжёлые задачи — только через `heavy`

Рендер видео (HyperFrames, Remotion, пачки скриншотов), перекодирование ffmpeg и расшифровку голосовых запускай так: `heavy <команда>`, например `heavy npx hyperframes render ...`.
- Без `heavy` рендер вместе с расшифровкой съедает всю память, и система убивает всю сессию: бот замолкает, последнее сообщение теряется.
- Помощнику-субагенту, который рендерит, пиши это правило прямо в задании — свои правила он может не увидеть.
- Два тяжёлых рендера одновременно не запускай, по очереди.
- Код выхода 137 = задаче не хватило памяти. Запусти её одну или с меньшим числом воркеров (`--workers 1`). Мне технические детали не пересказывай.
