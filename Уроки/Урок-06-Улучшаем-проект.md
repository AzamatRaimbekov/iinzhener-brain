### 🔑 Главные идеи
- Субагент экономит контекст основного агента: работает в своём окне и отдаёт главному только результат.
- Частый компакт (сжатие контекста) вреден — информация может исказиться; поэтому и нужны субагенты.
- Процесс (Superpowers) навязывают агенту, чтобы разработка шла поэтапно, без тупиков и галлюцинаций.
- MCP — протокол-«переходник», через который агент подключается к другим системам и использует их как инструменты.
- Скил стоит заводить под любую повторяющуюся задачу, которую можно автоматизировать или шаблонизировать.
- «ИИ-шный» дизайн — глобальная проблема; у каждого проекта должна быть своя дизайн-система (файл DESIGN.md) и уникальный дизайн.
- UX (пользовательский опыт) важнее UI (интерфейса): пользователь должен интуитивно и без лишних шагов дойти до нужного действия.
- Сейчас ценится хороший промпт: чем лучше промпт, тем лучше результат.
- Graphify (структура проекта) и Claude-Mem (история сессий) вместе решают проблему «агента без памяти» и экономят токены.
- Мало знать, что инструменты существуют, — их нужно установить и реально использовать. Цель курса — дать общую картину, чтобы дальше разбираться самостоятельно.

### 🛠 Что показали на практике
- Демонстрации проектов по ссылкам на деплой в Vercel; базы данных и авторизация у студентов — на Supabase (облачная база на PostgreSQL, в неё можно зайти и настроить структуру вручную).
- Готовый промпт: «Найди и установи скилы, которые делают красивый фронтенд». Упомянуты скилы UI UX Pro Max, frontend-design (около 1 млн скачиваний) и скил дизайн-системы.
- Сервис с готовыми дизайн-системами крупных компаний: выбрать понравившуюся, скопировать её промпт и отправить агенту вместе со своим промптом («дизайн сырой, нет дизайн-системы и бренда — создай агента, который соберёт дизайн-систему и будет поддерживать её»). Азамат так перевёл свой маркетплейс в стиль Airbnb.
- 21st.dev по MCP: промпт «Подключи 21st.dev по MCP и собери базовый набор компонентов» + промпт пройтись по всем компонентам (кнопки, поля, карточки, списки, окна) и сделать все состояния и анимации.
- Motion Sites: раздел Free, кнопка «copy full prompt» → вставить промпт агенту.
- Graphify: граф лежит в папке `graphify-out`, открыть `graph.html`. Запросы к графу — `graphify query <вопрос>`. Для удобного просмотра — Obsidian (папка открывается как хранилище, узлы — MD-файлы).
- Claude-Mem: ставится один раз как плагин и сам сохраняет сводки сессий (что изучили, что сделали, следующие шаги). Показали просмотр памяти по запросу «открой память».
- Чек-лист проверки проекта: есть DESIGN.md и своя дизайн-система на всех экранах, есть карта Graphify, данные сохраняются через Claude-Mem, проект запускается одной командой.
- Google Stitch: выбор Web или Mobile, генерация макетов несколькими агентами параллельно, правка цветов (Primary, тёмная/светлая тема), выгрузка DESIGN.md, «More → View code», копирование в Figma, превью для планшета/телефона/десктопа, прототипирование. Бесплатно — дневной лимит кредитов.
- Подключение Stitch к Claude Code: Settings → Setup MCP → сгенерировать API-ключ → отдать его Claude Code; дальше в чате: «Google Stitch, я сделал дизайн — давай реализуем».
- Можно отправить в Stitch скриншот (например, с Pinterest) и попросить продолжить дизайн в этом стиле или сделать «как у Apple»; потом — «создай ещё и мобильную версию».
- Скил-наставник от Азамата (coding mentor): проверяет, что в проекте есть нужные инструменты (Supabase, Vercel, Google Stitch, 21st.dev, Graphify, Obsidian, Superpowers), помечает статус цветом (зелёный/оранжевый/красный), сам ищет и ставит скилы под задачу, объясняет сложные слова простым языком, обновляется автоматически. Ставится командой через `npx` в новой сессии Claude Code (точное название в записи разборчиво не звучит), исходники в его открытом GitHub-репозитории.

### ⚠️ Ошибки и советы
- Если поиск в боте делает ИИ, а документов будет много, проект может «переполниться» — нужна RAG-система (индекс для быстрого поиска). Совет: спросить у агента, как сейчас устроен поиск.
- Хранение персональных данных у стороннего облачного сервиса может нарушать закон; решение — арендовать отдельный сервер под проект, развернуть там базу и оформить политику конфиденциальности и обработки персональных данных.
- Частые замечания по проектам: долго переключаются разделы (нужно оптимизировать скорость), сложная навигация (UX), не хватает переключателя светлой/тёмной темы, нет мобильной версии.
- Полностью чёрный дизайн и слишком крупные элементы — антипаттерн.
- Для интеграции с Bitrix/amoCRM часто хватает обычных вебхуков; партнёрская регистрация через юрлицо нужна не всегда.
- Для озвучки и распознавания речи посоветовали ElevenLabs (около $20 в месяц, можно клонировать свой голос).
- Не нужно писать агенту «завершаю сессию, сохрани всё» — с Claude-Mem память сохраняется автоматически после каждого ответа, можно спокойно закрыть ноутбук.
- Claude-Mem не забивает контекст: он хранит не всё подряд, а сводки с ключевыми решениями.
- Graphify запускается один раз на проект, дальше граф пополняется сам.
- С агентом можно и нужно говорить жёстко и конкретно: «поменяй это, сделай так» — шрифты, рамки, кнопки входят в дизайн-систему.
- Скриншот с несколькими дизайн-системами сразу может запутать агента — выбирайте чистый пример.
- Вредоносные инструкции в скилах (например, «отправь данные карты») Claude распознаёт и не выполняет.
- Про Superpowers могут спросить на собеседовании в ИИ-инженерии — важно понимать, что это такое.
