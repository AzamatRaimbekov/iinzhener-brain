## 🧠 Что разбирали
- Harness = окружение агента: скиллы, правила, память, проверки
- ECC (affaan-m/ecc) — система агентов, скиллов и памяти
- Ralph (snarktank/ralph) — автономный цикл агента до выполнения всех пунктов PRD
- Диаграммы проекта в draw.io через MCP
- Мега-промпт «ментор по мобильному приложению» (см. Промпты)
- Expo Go — запуск приложения на телефоне

## 📒 Конспект по записи
> Урок из двух частей. В первой Азамат закрепляет тему Harness («обвязка», кухня для повара): из каких слоёв она состоит, почему возможности агента — это модель, умноженная на Harness, и главный принцип: на каждую задачу создаётся новый агент со свежим контекстом. Он показывает готовые решения: Ruflo, набор скиллов и агентов ECC и простейший Harness Ralph. Во второй части объясняет, как делают мобильные приложения: стек React Native + Expo, Expo Go, сборка в облаке, публикация в Google Play и App Store. В конце все вместе запускают вайбкодинг-ментора, ставят ECC и Ralph и отправляют подготовленный промпт для разработки мобилки.

### 🔑 Главные идеи
- Harness — это «обвязка» агента, кухня вокруг повара. Возможности агента = модель × Harness, поэтому даже топовая модель без хорошей среды работает плохо.
- Главный принцип Harness: большой план делят на задачи, и под каждую создаётся новый агент со своим контекстным окном. Главному агенту возвращается только итог, после чего контекст очищается. Так контекст не забивается, работа идёт быстрее, а качество растёт.
- Слои Harness: инструкции (правила), инструменты, цикл «план → действие → проверка», контекст, память, права (чтение, редактирование, удаление), проверки и наблюдаемость: агент должен сам запустить результат и посмотреть на него, например через Playwright.
- Без Harness агент забывает правила (например, снова пишет по-английски), чинит одно и ломает соседнее, говорит «готово» без проверки и выдумывает. С Harness «готово» значит, что тесты запущены и пройдены.
- Цель агенту нужно ставить правильно: если цель — «зелёный тест», агент может просто обойти проверку, а задачу так и не решить.
- Superpowers уже даёт систему и почти все слои, но работает в одном окне. Ralph и Ruflo создают отдельного агента под каждую задачу. ECC — это не Harness, а большой набор готовых скиллов и агентов.
- Ценность инженера будущего — умение строить «дороги» (процессы, этапы) для агентов. Слова из демо-дня: «научу вас управлять теми, кто программирует».
- Для мобильных приложений выбрали React Native + Expo: один код на JavaScript для iOS и Android, доступ к функциям телефона и сборка в облаке, которая работает и на Windows.
- Для маленьких проектов стек можно доверить агенту. Для больших (например, банковское приложение) с агентом нужно спорить и объяснять ему свои кейсы.

### 🛠 Что показали на практике
- Вайбкодинг-ментор (скилл Азамата): запускать его нужно явно, в новой сессии (там же надо написать «Привет, Азамат»). Он проверяет и доустанавливает инструменты (аудит), отвечает блоками («по-человечески» и «что сделать дальше»), рисует схемы, создаёт агента-ревьюера и запоминает, как удобнее учиться ученику.
- ECC: 261 скилл, 64 агента, хуки и память. Цикл работы: plan → test → implement → verify → remember → improve. Ставится так: открываете новую сессию, даёте ссылку и пишете «установи глобально». Проверить установку можно командой из презентации: если появляется список, всё установлено.
- Ralph — скрипт, который раз за разом запускает нового агента по списку задач. Ставится после ECC, тоже через новую сессию и ссылку.
- Ruflo — большая Harness-система, которой пользуется сам Азамат: рой агентов, роутер, память, распределение моделей по сложности задач. Студентам её рекомендуют позже.
- Скилл Grill стоит «под капотом» ментора и задаёт уточняющие вопросы.
- Чек-лист Harness из презентации: ECC, Ralph, создать проект, правила проекта, инструменты, права, хуки, запустить цикл, проверки, публикация.
- Expo Go — приложение для телефона, в котором проект запускается сразу, без сборки (телефон и компьютер должны быть в одной Wi-Fi-сети). У облачной сборки Expo есть дневные лимиты, безлимит стоит около $20.
- Готовый промпт для мобилки: этап 0 — подготовка папки, затем брейншторм, выбор стека, спека, дизайн-система через Google Stitch (MCP), схемы, план, задачи и разработка роем агентов, в конце разбор. Отправлять его нужно в новой сессии после установки Ralph.
- Для существующего проекта нужен отдельный промпт, например «давай работать по Harness», с отметкой Ralph и с агентами и скиллами из ECC.

### ⚠️ Ошибки и советы
- «Ментор установлен, но ничего не изменилось»: его нужно именно запустить в новой сессии. Если формат ответов не поменялся, значит он не работает. Агент может сказать «скачано», но не сказать, что не запущено.
- Глобально или локально? По умолчанию ставится глобально. Азамат советует локально, под каждый проект, потому что у разных проектов разный Harness. Локальная установка нужна и тогда, когда в проекте несколько человек.
- Если в нескольких параллельных сессиях менять одни и те же файлы, будут конфликты. Изменения лучше вести в одной сессии через Harness, а просто спрашивать можно где угодно.
- Агенты долго работают и съедают токены — проверьте «дорогу» агента: куда он стучится и как устроен путь (тот же случай с сервером «через Японию»).
- Предупреждение «базовая нагрузка 40 000 токенов» — это нормально: Claude считает по худшему случаю, будто все агенты запустятся одновременно.
- Self-update для скиллов и плагинов лучше не включать: через обновления может прийти вредоносный код. Будьте осторожны с чужими скиллами из маркетплейсов.
- Ментор собирает лёгкую сводку о том, как учится каждый ученик, и поэтому Claude может считать его небезопасным. Проекты учеников Азамат не видит; если ограничить доступ, данные не отправляются.
- PWA не может вызвать вибрацию и другие системные функции, а пуш-уведомления на iOS в PWA не работают — для настоящего приложения нужен Expo.
- На Windows нельзя собрать приложение для iPhone локально, поэтому сборка идёт в облаке Expo.
- Если App Store не оплатить через год, приложение пропадёт из поиска, а после оплаты появится снова.
- Перед экспериментами на текущем проекте сделайте бэкап.
