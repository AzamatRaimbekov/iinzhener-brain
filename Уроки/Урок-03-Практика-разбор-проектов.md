### 🔑 Главные идеи
- Claude — ваш личный разработчик и помощник. Если что-то непонятно, просите его «объяснить простыми словами». Если он отказывается, переформулируйте задачу.
- Второй мозг — это обычные текстовые Markdown-файлы, связанные ссылками в граф. Claude переходит по ссылкам и читает нужное, а не всё подряд.
- CLAUDE.md — это инструкция для агента по конкретному проекту. Держите его до 200 строк: Claude читает его при каждом запросе, и длинный файл забивает контекст. Факты и правила выносите в отдельные файлы (design.md, PRD.md), а index.md служит оглавлением.
- Скил описывает, **как** что-то сделать (инструкция), а MCP даёт, **чем** это сделать (инструмент). Плагин — это набор, в котором есть и скилы, и MCP.
- Claude выбирает скил сам: он читает короткое описание в начале каждого скила. Два скила под одну задачу (например, два для дизайна) мешают друг другу, лучше оставить один.
- graphify ставится не глобально, а под каждый проект: граф строится для конкретного проекта.
- «Нет невыполнимой задачи, есть ещё не установленный MCP».
- Ваша экспертиза в своей сфере важнее кнопок и интерфейса — это главная основа продукта, на ней можно зарабатывать.
- По любому инструменту можно спросить Claude, нужен ли он вашему проекту. Он знает проект и посоветует.

### 🛠 Что показали на практике
- Скил Grill Me: запуск через `/grill-me` или словами «используй скил grill me». В интерфейсе видно строку «Run skill», значит скил запустился. Claude задаёт много вопросов и рядом с одним из вариантов ответа пишет «рекомендую».
- Скил Watch: разбивает YouTube- или Instagram-видео на кадры (например, каждые 0,5 с) и анализирует их. С его помощью Рамис повторил чужой ролик примерно на 80%, а потом адаптировал его под свой продукт Fusion AI. Claude работал около 40 минут и сделал ролик на 30 секунд.
- Установка через find-skills: «найди skill watch и установи его».
- Плагин Hyperframes (анимированные обучающие ролики): Claude Code дают ссылку на документацию и пишут «Установи Hyperframes». Если он установился только в папку проекта, можно попросить установить глобально.
- Скил Agent Reach (в записи звучит как «agent rich» / «Agent Research»): Claude открывает почти любые ссылки и ищет информацию в интернете.
- Open source CRM с GitHub: Claude дают ссылку на репозиторий и просят взять только нужное.
- Расширение Claude in Chrome: установить, закрепить через значок пазла и войти в аккаунт. Пример задачи: «найди топ-5 магазинов велосипедов в Бишкеке по отзывам» на сайте 2ГИС. Ещё с его помощью заполняли анкеты и покупали и привязывали домен. Работает только в Google Chrome.
- Связка двух ИИ: Claude Code пишет промпт для Claude в Chrome (например, чтобы разобраться в интерфейсе Supabase), а ответ вы копируете обратно в Claude Code.
- Granola AI — запись и анализ звонков (Google Meet, Zoom) и офлайн-встреч.
- Composio: Settings → API key → Setup CLI → Claude Code. Инструкцию копируете в Claude Code со словами «Установи мне». Дальше подключаются Instagram, YouTube, Gmail, Google Sheets, WhatsApp (только чтение и анализ переписок), ElevenLabs, Google Meet, Geoapify.
- Ролики с аватаром: аватар делают в HeyGen (в настройках Developers есть MCP), монтаж — в Diffusion Studio («Установи себе Diffusion Studio»), вставки Claude ищет сам. Если попросить, чтобы 70% ролика были видеовставками, результат становится разнообразнее.
- Правило в CLAUDE.md, чтобы Claude всегда отвечал по-русски и простыми словами.

### ⚠️ Ошибки и советы
- Скил «не устанавливается» или Claude говорит, что его нет: скорее всего, он стоит в другом проекте, а не глобально. Попросите Claude проверить, что установлено, и для сторонних задач открывайте новый чат.
- Не понимаете, куда положить файл (например, design.md)? Попросите Claude сделать это самому: он умеет создавать и перемещать файлы.
- Если скил не появился в выводе как запущенный, значит он не сработал или Claude не понял, какой скил нужен.
- Claude отвечает по-английски: добавьте в CLAUDE.md правило отвечать на русском.
- Если вы не уверены, стоит ли graphify, спросите Claude: «стоит ли у меня graphify?»
- Для разных проектов делайте разные папки, чтобы не смешивать контекст.
- Claude in Chrome не работает в других браузерах, сначала установите Google Chrome.
- С примером (референсом) результат всегда лучше. Красивый дизайн дашборда сделали, просто дав Claude скриншот из Pinterest.
- Совет по проектам: подключать реальные данные (API AmoCRM или Bitrix, интернет-магазинов), а для складского учёта искать готовый open source.
- Когда Claude говорит про авторские права (например, на музыку), он может отказаться брать чужое.
