### 🔑 Главные идеи
- Правильный порядок работы: подробный план в обычном чате → план кладём в папку проекта → Claude Code собирает проект локально → дорабатываем → деплоим.
- Обратный промптинг: допишите в промпт «задавай вопросы, прежде чем начать», и ИИ сам вытащит из вас недостающий контекст.
- Агент не помнит проект между чатами и каждый раз перечитывает папку. «Второй мозг» (CLAUDE.md плюс связанные MD-файлы) экономит токены и время, потому что Claude читает только нужные файлы.
- В CLAUDE.md пишут, что это за проект и для кого, стек, где что лежит и договорённости, которые не видны из кода. Пересказывать код и писать общие слова вроде «пиши чистый код» не нужно.
- Когда CLAUDE.md разрастается больше чем на ~200 строк, выносят карту проекта в INDEX.md (как оглавление книги со ссылками на PRD, roadmap, стек, дизайн).
- MCP даёт агенту новые возможности, а скил учит, как ими пользоваться. Ставьте только нужные MCP: каждый занимает контекстное окно, а похожие MCP могут конфликтовать.
- Vercel хранит и публикует сайт, Supabase хранит данные (пользователей, заявки, заказы). Это разные вещи.
- Изменения копятся локально и попадают в интернет только после команды задеплоить.
- Скил — это текстовый файл-инструкция. Свой скил можно сделать за ~10 минут: отладить задачу в чате и попросить «оберни это в скил».
- 99% технической работы Claude делает сам. Ваша задача — понимать общую картину и давать ему инструкции по установке.

### 🛠 Что показали на практике
- Промпт для плана в чате ChatGPT или Claude: `Распиши мне план для Claude Code, чтобы он сделал ... Задавай вопросы, прежде чем начать`. План можно сразу попросить в формате MD или Word.
- Создали папку на рабочем столе, положили туда план, в Claude Code выбрали её через **Open folder** и дали промпт: `В этой папке лежит план моего проекта. Посмотри его и начни строить. Дай максимально быстро первую страницу кликабельную`.
- Слэш-команды Claude Code: `/init` (создать CLAUDE.md), `/mcp` (открыть список коннекторов).
- **Graphify** — установка по команде из презентации, затем промпт вроде «построй граф связей / второй мозг» (работает около 30–40 минут).
- **Vercel**: установка MCP командой из презентации (`установи глобально`) или через Customize → Connectors → Browse connectors → Connect. Регистрация через Google (Sign up), создание проекта, доступ «All», Allow. Потом промпт `Задеплой на Vercel и дай ссылку`.
- **Supabase**: Customize → Connectors → поиск «Supabase» → «+». Регистрация по почте с подтверждением, бесплатный план.
- MCP без регистрации: **Context7** (актуальные версии библиотек) и **Playwright** (Claude сам открывает браузер и прокликивает сайт). **Magic MCP** от 21st.dev (красивые компоненты) требует ключ.
- Скилы ставятся командой `npx skills add ...` из презентации: **Grill Me** (дотошно расспрашивает перед работой), **Find Skills** (ищет и ставит другие скилы), **UI UX Pro Max**, **Impeccable** (59 правил дизайна, чтобы сайт не выглядел «сделанным ИИ»). Флаг `-g` ставит скил глобально.
- Примеры скилов Рамиса: humanizer (очеловечивает текст), промпт-архитектор для чат-ботов, контент-партнёр для сценариев Reels. Упомянуты скилы Skill Creator, agent research (смотреть посты Instagram) и watch (визуально смотреть видео).
- Проверка установленных MCP: галочка в Customize → Connectors или вопрос к Claude («ты видишь Supabase?» / «проверь, какие MCP установлены»).
- Сайты для дизайна: **Motion Sites** (кнопка «Copy full prompt» воссоздаёт блок сайта), **shadcn/ui**, **Refero Styles** (библиотека дизайн-систем с файлом DESIGN.md).
- Голосовой ввод: Wispr Flow и аналоги — по горячей клавише текст надиктовывается в любое поле.

### ⚠️ Ошибки и советы
- На уроке просили сделать только первый экран, потому что весь план Claude может делать 2–3 часа. Дома запускайте полную сборку и спокойно ждите.
- После установки MCP перезапускайте Claude полностью, иначе MCP может не заработать.
- Если Claude пишет, что не может что-то установить (например, нужен Node.js), прочитайте его инструкцию и выполните шаги. Можно сказать ему «установи сам».
- На корпоративных компьютерах без прав администратора установка может не пройти. Нужно просить доступ или работать на своём компьютере.
- При входе в Vercel у многих не было аккаунта: нужно нажать **Sign up**, а не логин. Vercel просит карту для free trial, деньги при этом не списываются.
- Если ссылка Vercel открывается только у автора, попросите Claude открыть публичный доступ.
- Если MCP поставили и через терминал, и через коннектор, появляется дубль. Достаточно одного способа.
- В калькуляторе у студента подставились рубли по умолчанию: это от нехватки контекста. Такие ошибки ловит Grill Me.
- Скил может не запуститься, если Claude его «не видит». Пропишите его в CLAUDE.md или прямо укажите в промпте «используй этот скил». Хорошее описание скила (верх файла) помогает Claude понять, когда его запускать.
- Вопрос: почему Claude переключается между русским и английским? Ответ: так работают его внутренние инструменты, пока это знать не нужно.
- Вопрос: списываются ли деньги за MCP? Ответ: нет, если сами не привязали оплату. Большинство MCP бесплатные.
- Интеграции с 1С и Telegram сложнее, их разберут позже. Перенос большого готового приложения на другой язык — отдельная сложная задача (анализ, спецификация, система агентов).
- Пароли от сервисов лучше не забывать. Если забыли, сбрасывайте через почту.
