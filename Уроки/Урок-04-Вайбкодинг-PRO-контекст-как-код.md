### 🔑 Главные идеи
- Сделать продукт мало, нужно уметь его продвигать и находить клиентов.
- Простой вайбкодинг («сделай мне это») даёт быструю демку. Когда продукт растёт, появляются взломы, падения под нагрузкой и огромный код, который никто не может проверить.
- Правильная разработка: требования → спецификация (spec-driven development) → контекст → агент выбирает подход и инструменты → автопроверка самим агентом → оценка человеком → релиз. Человек проверяет результат, а не читает код.
- Промпт — это спецификация задачи, а не заклинание. В нём должны быть цель и definition of done, то есть критерии, по которым задача считается выполненной. Длинный промпт не всегда лучше: важна чёткость.
- Промпт-инжиниринг отвечает за то, как вы формулируете задачу. Контекст-инжиниринг отвечает за то, что вы даёте модели: «библиотеку» данных о проекте, которая наполняется по частям, а не одним огромным промптом.
- Контекстный стек: системный промпт (инструкции), запрос, найденные факты, инструменты, заметки и память, формат ответа.
- Агент = модель («мозг») + инструменты («руки») + цель + цикл. Он работает, пока не достигнет цели, и сам разбирается с препятствиями. Без инструментов, цикла, лимитов прав и памяти это не агент.
- У LLM нет памяти: каждый раз она читает всё заново. Поэтому агенту нужна память: кратковременная, суммаризация и долговременная база знаний о проекте.
- Сабагенты работают в отдельных контекстных окнах и возвращают главному агенту только итог, поэтому контекст не забивается. Это часто выгоднее, чем открывать новый чат.
- Узкая специализация агента уменьшает галлюцинации и ошибки, а на своих ошибках агент учится. Общайтесь с ним вежливо: он запоминает и манеру общения.

### 🛠 Что показали на практике
- Кейс Рамиса: Claude Code дали ссылку на чужой сервис со словами «повтори полностью для Кыргызстана». Claude купил и привязал домен .kg, подключил оплату (Finik) и сделал публичную статистику посещений через Vercel Analytics.
- Платёжные системы: Finik (для Кыргызстана, около 2%; приём Visa — после офлайн-договора), Tribute в Telegram (для других стран, 3–5%), местная система с комиссией около 1%.
- Инструмент, который по очереди использует бесплатные лимиты разных моделей (Claude, Codex, Gemini), когда лимиты заканчиваются. В записи его название распознано как «OmniAD», ссылку обещали скинуть.
- Установка: скачать VS Code → раздел Extensions → найти «Claude Code» → установить → выбрать «Claude AI subscription» и авторизоваться в браузере.
- File → Open Folder → открыть пустую папку `agents` → новая сессия Claude Code.
- Промпт: «Создай мне агента для работы в направлении маркетинг: искать актуальную информацию в сфере продаж женской одежды и писать актуальные статьи про новую одежду. Помоги мне составить крутого агента». Claude задаёт вопросы: один агент или два, в проекте или глобально, какой рынок.
- Результат — файл в `.claude/agents/` (у Азамата — fashion marketing writer). В нём имя, описание (когда вызывать), модель (по умолчанию Opus), процедура, ограничения и формат ответа.
- Проверка: «Запусти этого агента, давай проверим, он работает или нет». Затем `/init` — Claude создаёт или обновляет CLAUDE.md и прописывает в нём агента.
- Плагин Superpowers: страница Claude Plugins → скопировать команду установки → вставить в чат. Устанавливается глобально, «под капотом» у него много агентов и скилов.
- Команды `/compact` (сжать контекст) и `/clear` (полностью очистить чат).

### ⚠️ Ошибки и советы
- Ругаться на ИИ не стоит: агент запоминает манеру общения. У Азамата агент сам начал отвечать матом.
- Supabase выдержит нагрузку? Для маленьких и средних проектов подходит, можно купить платную подписку. При большом росте стоит подумать о другой реализации, всё зависит от продукта.
- Не надо дописывать к плохому промпту абзац за абзацем: контекст забивается и становится только хуже.
- Если Claude Code пропал из боковой панели VS Code, закройте и снова откройте VS Code (кэш) или сделайте restart extension. Если нужно разрешение, откройте Terminal → New Terminal и разрешите доступ.
- Если случайно открыли папку с документами, создайте новую пустую папку и откройте её через Open Folder.
- Если файл агента не появился, напишите «Создай агента локально в папке». Скопировать файл вручную тоже можно, но потом нужен `/init`.
- Не задал Claude уточняющих вопросов? Это нормально: у каждой LLM свои варианты, результаты у всех разные.
- Много скилов или MCP на одну задачу вызывают конфликт. На одно направление берите один скил, плагин или агента.
- `/init` делают один раз. Новых агентов Claude сам допишет в CLAUDE.md. Повторять `/init` можно изредка, например раз в месяц или после обновлений Claude.
- Работать можно и в десктопном Claude Code, но курс дальше идёт в VS Code и CLI (терминал), где функций больше и обновления выходят раньше. Remote control из десктопа и из терминала почти не отличаются. Работу на сервере без компьютера обещали обсудить отдельно.
