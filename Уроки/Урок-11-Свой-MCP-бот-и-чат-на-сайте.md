> Урок практический: делаем «пять крутых вещей, которые умеет каждый вайбкодер», из них успели три. Сначала студенты с помощью готового скилла build MCP server создали собственный MCP-сервер для своего сайта, задеплоили его на Vercel и подключили к Claude через Connectors. Затем через BotFather сделали простого Telegram-бота на кнопках. В конце по готовому промту добавили на сайт чат-ассистента в углу экрана, который работает на бесплатном API-ключе Grok. RAG (чтобы ассистент знал содержимое проекта) и создание своих скиллов не успели и оставили на дом.

### 🔑 Главные идеи
- Главная мысль всего курса: не бойтесь, начните разбираться. Сегодня один человек может сделать то, для чего раньше нужна была целая команда.
- MCP придумала Anthropic, чтобы агенты экономно по токенам вызывали методы вашего проекта. Какие инструменты разрешены (прочитать, создать заказ, удалить и т.д.), решаете вы сами.
- У серьёзного сервиса сейчас должен быть свой MCP. Преподаватель сказал, что без MCP ему с продуктом даже работать не хочется.
- Для работающего MCP нужны домен, защищённый протокол HTTPS и страница с инструкцией по подключению. Если настроить всё правильно, сервер могут найти и подключить другие пользователи, поэтому нельзя случайно открыть всему миру свои данные.
- Можно закрыть доступ к MCP авторизацией (токен, код, whitelist) или сделать его платным по тарифу.
- Telegram-бот — просто посредник между чатом в Telegram и вашей программой. Логика бота живёт в вашем проекте. Бывает два режима: готовые ответы на кнопках и бот с ИИ.
- ИИ-агента можно встроить в сайт, приложение или Telegram-бота: это как «засунуть Claude в свой проект». Без RAG агент не знает, о чём ваш проект.
- Claude нельзя слепо верить. Просите доказать: «Сделай так, чтобы я убедился». Понимание, когда ему верить, приходит со временем.
- «Нельзя бояться Claude — нужно, чтобы он боялся вас».

### 🛠 Что показали на практике
- Скилл **build MCP server**: в новой сессии Claude Code отправить промт шаг 1 (установка), ответить на вопросы, затем отправить промт шаг 2, где в скобках описать проект, данные и нужные операции.
- Claude сам добавляет на сайт раздел/плашку MCP с инструкцией по подключению. У некоторых MCP-сервер поднялся отдельным проектом на Vercel.
- Деплой простым промтом в духе «сделай деплой на Vercel, туда, где мы поднимали сайт».
- Подключение в Claude: Connectors → «Добавить» → название → вставить адрес сервера → Connect → разрешить использование (Always allow). Если сервер с авторизацией, нужно ввести токен или код. Если сервер уже добавлен, появится ошибка «already exists».
- Проверка: в новом чате написать «используй MCP <название> и дай актуальную информацию».
- Демо собственного проекта «Ордо»: транскрибация встреч, разделение спикеров (диаризация), двуязычная речь, протокол, задачи, календарь, отправка в Telegram и WhatsApp, встроенный чат-ассистент.
- Telegram: найти **@BotFather** («отец ботов»), Start → Create new bot, задать уникальное имя с окончанием `_bot`, скопировать токен, вставить его в промт со слайда 9 и отправить в новую сессию Claude.
- Чат-ассистент: в консоли Grok нажать Create API token, задать имя, выбрать No expiry, нажать Submit и скопировать ключ. Ключ вставить в промт со слайда 13 вместо заглушки, промт отправить в проект сайта. В углу сайта появится чат, внутри работает Grok.
- После этого бота можно дорабатывать промтами в том же чате, например: «у нас есть Telegram-бот, давай улучшим».

### ⚠️ Ошибки и советы
- Частая ошибка: промт шага 2 вставили как есть. Свой текст нужно вписать в выделенные места (в скобках/зелёным).
- Лучше открыть отдельную папку или новую сессию под задачу. Так Claude ничего не сломает в основном проекте (студент рассказал, как Claude предложил удалить сайт и оставить только лендинг).
- Если Claude пишет, что «Git пустой», значит, проект не был залит в Git/Vercel и истории версий нет.
- Вопрос: «Получат ли другие доступ к моим данным через мой MCP?» Ответ: только если вы так настроили. Закрывайте доступ авторизацией (whitelist, токен). На уроке MCP делали открытым для простоты.
- Вопрос: «Где хранится переписка с чат-ботом?» Ответ: у провайдера, который выдал API-ключ (Grok).
- Вопрос: «Увидят ли другие чат на моём сайте?» Ответ: как настроите, так и будет. Можно попросить Claude скрыть его от посетителей. Защите будет посвящён следующий урок.
- API Claude оплачивается отдельно от подписки, поэтому на уроке взяли бесплатный тариф Grok.
- Telegram-бот должен работать после деплоя: на localhost он работать не будет.
- В бесплатном Telegram число ботов ограничено (по словам преподавателя, около 20).
- Не загружайте мобильное приложение в магазин, пока оно не готово: могут отклонить или заблокировать.
- Если чат-бот отвечает общими фразами и не знает ваш сайт, ему не хватает данных о проекте, то есть RAG.
