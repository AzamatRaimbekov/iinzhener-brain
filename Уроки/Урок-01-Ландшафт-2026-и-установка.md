### 🔑 Главные идеи
- На курсе не учат языкам программирования. Учат управлять ИИ так, чтобы он писал код за вас, а вам нужно понимать логику того, что он меняет.
- LLM угадывает следующий токен, поэтому может уверенно ошибаться (галлюцинировать). Важные ответы нужно перепроверять.
- Следите за контекстным окном. Один чат — одна тема, для новой задачи открывайте новый чат. При заполнении примерно на 65% лучше начать новую сессию, а к 95% модель начинает сильно галлюцинировать.
- Модели разного размера: Opus и Fable умнее и дольше рассуждают (цепочка мыслей), но тратят больше ресурсов. Sonnet подходит для простых рутинных задач. Сложные задачи отдавайте умным моделям.
- Агент — это модель, которой дали инструменты, а иногда ещё и циклы повторения. Сама модель — «мозг», инструменты — «тело».
- Плохой промпт — это «сделай мне сайт». В хорошем промпте есть задача, контекст, примеры, роль, формат ответа и тон.
- Примерно 80% времени уходит на текстовое описание того, как всё должно работать. Сначала план, потом прототип, потом основной продукт.
- Проект — это папка. В CLAUDE.md лежит инструкция для ИИ о проекте, чтобы не объяснять всё заново в каждом новом чате.
- MCP — это «руки» ИИ, готовый протокол подключения к сервисам, удобный для ИИ (удобнее, чем голый API). Скил — это текстовая инструкция-навык. Плагин — набор MCP и скилов.
- Хороший проект закрывает реальную боль, лучше из вашей профессии. Его можно объяснить одним предложением, первая версия готова за 1–2 недели, и им пользуется хотя бы один живой человек.

### 🛠 Что показали на практике
- Скачивание **Claude Desktop** только с официального сайта (версии для Mac и Windows).
- Устройство приложения: переключатель Home/Code, режимы **Chat**, **Cowork** (работа с файлами в выбранной папке, панель прогресса и контекста) и **Code**.
- Настройки Claude Code: выбор папки проекта, режимы прав (только план, подтверждение каждого изменения, автоправки, **bypass permissions**), выбор модели, ползунок effort (вплоть до режима с параллельными агентами), кружок-индикатор контекстного окна.
- Customize: **Skills**, **Connectors** (MCP: Gmail, Canva, Google Drive, Google Calendar и др.) и **Plugins**.
- Установка **Git** с официального сайта. На Mac — через **Homebrew**. Если Homebrew нет, текст ошибки можно отправить в Claude, и он подскажет, как её исправить. На Windows — обычный установщик (Windows 64 Setup).
- Терминал: на Mac — приложение «Терминал» (через поиск), на Windows — PowerShell. Проверка, что Git установлен: команда версии (`git --version`). Один раз настраиваем имя и email: `git config --global user.name` / `user.email`.
- При установке Git на Windows для открытия файлов советовали выбрать Chrome (чтобы HTML-файлы открывались в нём).
- Проверочный промпт в новой пустой папке: `Создай лендинг как пример на localhost`. Сайт открылся по адресу вида `localhost:3000`.
- В настройках (General) включили все переключатели доступа и проверили на Mac разрешения Accessibility и Screen Recording.
- Для самостоятельного изучения назвали браузерные билдеры: Lovable, Bolt, v0, Replit. Среди IDE упомянули Cursor, Windsurf, Antigravity; на курсе будет VS Code.

### ⚠️ Ошибки и советы
- Вопрос: почему одни модели «едят» больше ресурсов? Ответ: умные модели дольше рассуждают (цепочка мыслей) и сами себя проверяют, поэтому тратят больше.
- Вопрос: чем Claude лучше ChatGPT? Ответ: под Claude есть много готовых интеграций и инструкций; по словам разработчиков, он пишет более чистый и компактный код, у него больше контекстное окно, и он сильнее в архитектуре и рассуждениях. Codex, Gemini и Cursor тоже можно использовать.
- Вопрос: как агенту не сжечь все токены в цикле? Ответ: это разберут на уроках Азамата про агентные системы.
- Подписка: в бесплатной версии лимиты сильно урезаны, нет умной модели и Cowork. Pro за $20 на разработку не хватит, рекомендуют план за $100.
- Не покупайте несколько аккаунтов по $20 на одном компьютере: Claude может их заблокировать.
- Ссылкой `localhost:...` не делитесь, она открывается только на вашем компьютере. Чтобы другие увидели проект, его нужно задеплоить.
- Хорошая разработка идёт в три стадии: локально, затем dev-сервер для тестирования, затем prod (боевая версия).
- Если сразу после установки Claude Code горит красная ошибка про Git, нужно установить Git.
- Claude сам ограничивает себе доступ к компьютеру ради безопасности, поэтому некоторые команды (например, установку Homebrew) приходится вводить вручную. На Windows отдельные разрешения Accessibility/Screen Recording не нужны.
- Не берите проекты, где нужен доступ к закрытым гос. системам без API/MCP. Не делайте «ещё один Instagram/Uber» и не берите три идеи сразу. Сначала спросите у будущих пользователей, нужен ли им продукт.
- Если работаете с чувствительными данными, их можно обрабатывать открытыми моделями на своей инфраструктуре; это обсудят индивидуально.
