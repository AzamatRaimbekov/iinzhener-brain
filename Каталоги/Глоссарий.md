## RAG
RAG (Retrieval-Augmented Generation) — это технология, которая дает нейросети доступ к внешней базе данных перед тем, как она сгенерирует ответ.
Обычная языковая модель (LLM) похожа на студента на закрытом экзамене, который отвечает исключительно по памяти. Система с RAG — это студент с открытой книгой: сначала он находит нужный параграф в справочнике, а потом на его основе пишет грамотный ответ.

_Источник: [#330](https://t.me/c/3898352903/330)_

## RAG vs «просто закинуть файл»
Встроенный ИИ-помощник (Gemini) в Cloud Code действительно прочитает ваш файл и ответит по нему.
Но здесь есть важная разница между помощником для вас и RAG-системой:

1. То, о чем говорите вы (Контекст в редакторе):
Вы закинули файл в Cloud Code, открыли его и спросили ИИ: "О чем этот документ?" или "Найди тут ошибку".
ИИ прочитал то, что лежит у вас перед глазами, и ответил. Это отличная функция редактора, но она работает только для вас в моменте. Это как дать другу почитать листочек, который вы держите в руках.

2. То, что такое RAG на самом деле (Отдельная система):
RAG — это когда вы создаете самостоятельную программу (например, бота для Telegram, WhatsApp или сайта).
В эту программу вы загружаете не один листочек, а целую библиотеку (тысячи документов, прайс-листов, инструкций). И когда уже ваш клиент или пользователь задает боту вопрос, система сама автоматически ищет нужный абзац среди этих тысяч файлов и выдает точный ответ. Вас в этот момент за компьютером вообще может не быть.

Итог:
Если вам нужно просто спросить ИИ про один ваш файл — достаточно просто закинуть его в Cloud Code.
А вот если вы хотите сделать так, чтобы ИИ отвечал по вашим файлам другим людям в автоматическом режиме, тогда вам нужно написать ту самую RAG-систему (что мы и обсуждали в первом ответе).

## Harness (харнесс)
Харнесс для ИИ-агента — это безопасный тренировочный полигон и инфраструктурный каркас вокруг нейросети.

Представьте, что вы создаете ИИ-агента для автоматизации продаж в WhatsApp или Telegram. Прежде чем пускать бота к реальным клиентам, нужно убедиться, что он не раздаст фейковые скидки, правильно запишет лида и не зависнет от странного вопроса. Для этого его помещают в харнесс.
Если нейросеть — это повар, а ваш системный промпт — это рецепт, то харнесс — это полностью оборудованная профессиональная кухня.

Что именно делает эта «кухня»:
Создает безопасную иллюзию (Песочница): Агент думает, что заносит данные в настоящую CRM-систему или отвечает живому человеку, но всё происходит в симуляции. Бот может тестировать любые действия без риска что-то сломать в реальном бизнесе.
Дает удобный доступ к инструментам: Харнесс правильно подключает к агенту все нужные внешние функции (API, календари, базы знаний), чтобы бот мог не просто болтать, а выполнять полезную работу.

Устраивает автоматические экзамены: Вместо того чтобы вручную переписываться с ботом, харнесс прогоняет его по сотням тестовых сценариев — от идеального диалога до попыток взломать промпт. Затем он оценивает, насколько четко агент следовал заданному воркфлоу.


В итоге харнесс берет на себя всю сложную техническую рутину, превращая набор текстов и API в стабильный, предсказуемый и безопасный продукт.

## CLI и Claude Code CLI
CLI (Command Line Interface) — это интерфейс командной строки, или попросту терминал (тот самый классический черный экран с текстом). Здесь вы управляете компьютером не кликая мышкой по кнопкам, а печатая команды. Это то самое место, где обычно запускаются процессы вроде ⁠npm run dev⁠ для поднятия локального сервера или ⁠git push⁠ для отправки кода на GitHub.

Claude Code CLI — это новый инструмент от компании Anthropic. Они буквально поселили свою нейросеть Claude прямо в этот терминал.

_Источник: [#333](https://t.me/c/3898352903/333)_

## Скилл (skill)
Папка с инструкцией `SKILL.md` (и скриптами), которую Claude подгружает сам, когда задача подходит под описание скилла. Ставятся через `npx skills add …` или плагины.

## Плагин
Набор скиллов/агентов/команд/MCP одним пакетом из маркетплейса (claude.com/plugins). Каждый плагин расходует токены — ставьте только нужные.

## MCP (Model Context Protocol)
Способ подключить к Claude внешний сервис или данные (Stitch, Context7, draw.io, ваш собственный сервер). См. [[Урок-11-Свой-MCP-бот-и-чат-на-сайте|урок 11]].

## Деплой
Выкладка проекта в интернет (Vercel, Railway, свой сервер), чтобы он открывался по ссылке.
